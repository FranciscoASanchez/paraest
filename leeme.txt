paraest — Ajuste de parámetros de modelos termodinámicos (GCA-EoS)
=================================================================

Compilar
--------
    make                  con Intel ifx (por defecto)
    make FC=gfortran      con GNU gfortran
    make debug            versión con verificaciones -> debug.paraest.x
    make clean            borra objetos y ejecutables

Antes de usar ifx, cargar el entorno de Intel:
    source /opt/intel/oneapi/setvars.sh

Ejecutar
--------
    ./paraest.x           lee paraest.dat (y FOR010-013.DAT) del directorio actual

Prueba de regresión
-------------------
    make prueba

Corre paraest.dat en pruebas/tmp/ y compara paraest.out, graficos.csv y
tables.csv con pruebas/referencia/ (tolerancia relativa 1e-6). Hay que
correrla después de cada cambio: si da "Regresión FALLÓ", el cambio alteró
los resultados.

Organización
------------
    src/principal/     programa principal, lectura/escritura, FUNC
    src/optimizacion/  optimizadores (ZXSSQ: Marquardt-Levenberg)
    src/modelos/       modelos termodinámicos (GCA y la versión "assoc")
    src/equilibrio/    cálculos de equilibrio (flash, psat, isofugacidad...)
    pruebas/           prueba de regresión y salidas de referencia
    Archivos/          conjuntos de datos experimentales
    legacy/            versiones viejas de los fuentes y makefiles

Las versiones se llevan con git (git log, git tag), no en el nombre de
los archivos.
